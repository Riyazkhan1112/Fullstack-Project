Simple definition:

Hooks are special functions in React that help us use features like state, API calls, and other React functionality inside functional components.

Why do we use Hooks?

Before Hooks, we used class components to manage state and lifecycle methods. Now, we can do these things using functional components and Hooks.

For example:
- useState – Store data  - manage component data manage state in functional components.. Whenever the state changes, React re-renders the component and updates the UI
- useEffect – .useEffect is a React Hook used to handle side effects, such as API calls, timers, subscriptions, and event listeners.
